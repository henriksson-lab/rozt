# Two-channel gradient OME-Zarr fixture

A synthetic 2×8×16×16 (C/Z/Y/X) uncompressed Zarr v3 two-level OME-NGFF pyramid, ~13 kB.

It exists because every other committed fixture is single-channel (`[z, y, x]`), so nothing
exercised the portable renderer's multi-channel paths end to end.

Each channel carries a different analytic gradient — channel 0 ramps along x, channel 1 along y —
so the two are never equal except at the origin. That matters for residency testing: several
demand-resident channels share one page table, and a key collision is only *visible* if reading a
neighbour's page yields a different scalar.

Generated by `scripts/prepare_two_channel_fixture.py`. Synthetic data, no third-party source.
